# Windows IT Support and Ticket Resolution Lab

Completed five simulated support tickets in a Windows 11 Pro
virtual machine using VMware Workstation and PowerShell.

## Tickets completed

1. Re-enabled a disabled local account and verified sign-in.
2. Corrected folder permissions and verified file editing.
3. Started Print Spooler and verified printer enumeration.
4. Restored a working DNS server address and verified lookups.
5. Restored a deleted file and verified matching SHA256 hashes.

## Skills practiced

- Local account management
- NTFS permissions
- Windows service troubleshooting
- DNS diagnostics
- File restoration and integrity checks
- Support ticket documentation

## Lab scope

All issues were deliberately simulated in my home lab.
Accounts were local Windows accounts.
Printer testing did not include submitting a print job.
The backup was on the same virtual disk.
The DNS address was restored as an explicit setting;
the original automatic/manual DNS mode was not recorded.
